Mi Recomendación Principal

Void Linux

Sitio Oficial

Distribución independiente de rendimiento extremo. Destaca por utilizar runit como sistema de inicio en lugar de systemd, acelerando el arranque y manteniendo la RAM en mínimos.

RAM BASE ~60 MB
INIT SYSTEM runit
GESTOR XBPS
Máximo Minimalismo

Alpine Linux

Sitio Oficial

Diseñada con un enfoque absoluto en la eficiencia, seguridad y simplicidad. Basada en musl libc y busybox, es tan compacta que puede ejecutarse completamente en memoria RAM.

RAM BASE ~30 MB
C LIB musl
GESTOR APK
